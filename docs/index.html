📄

KSeF FA(3)

Pełna integracja z Krajowym Systemem e-Faktur 2.0. Wysyłka, odbiór, UPO, kody QR, tryb offline24. Zgodne z mandatem od 2026-04-01.

📊

JPK_V7M(3) i JPK_V7K(3)

Generator XML zgodny ze schematem MF z 2025-12-19. Strict XSD compliance — namespacy, kolejność elementów, typy danych zweryfikowane.

📈

JPK_KR_PD (JPK_CIT)

Pełny generator z sekcjami Naglowek, Podmiot1, ZOiS, Dziennik, KontoZapis, Ctrl, RPD. Termin: 31 lipca 2027 dla typowej sp. z o.o.

⚪

Biała Lista

Automatyczna weryfikacja kontrahentów przy płatnościach > 15 000 zł. Wbudowane w Odoo 19 — brak osobnego modułu.

💸

MPP (Split Payment)

Mechanizm Podzielonej Płatności w fakturach KSeF (P_18A). Auto-sugestia gdy wartość przekracza 15 000 zł.

👥

ZUS / PIT

Płace, ZUS DRA/RCA, PIT-4R, PIT-11. Moduł vitalibondar (LGPL-3) zintegrowany przez setup script.

💰

NBP kursy

Codzienne kursy walut z Tabeli A Narodowego Banku Polskiego. Bez kluczy API, bez subskrypcji.

🏢

Środki trwałe

Pełna amortyzacja przez OCA account_asset_management. Liniowa, degresywna, kombinacja, prorata.

📚

Raporty księgowe

Zestawienie Obrotów i Sald, Dziennik, Rozrachunki wiekowane, Open Items — przez OCA account_financial_report.

Prezes podpisuje sam

Po deregulacji z 2014 r. (Dz.U. 2014 poz. 768) nie ma już wymogu certyfikatu dla osoby prowadzącej księgi wewnątrz firmy. To zmienia model biznesowy.

Podstawa prawna

Art. 4 ust. 5 UoR — zarząd może powierzyć prowadzenie ksiąg sam sobie (pisemne oświadczenie).

Art. 52 ust. 2 UoR — sprawozdanie podpisuje "osoba prowadząca księgi" i "kierownik jednostki". Gdy to ta sama osoba — wystarczy jeden podpis.

Deregulacja 2014 — usunięto wszystkie wymogi kwalifikacyjne dla wewnętrznej księgowości.

Szybki start (5 minut)

Pełne wdrożenie od zera. Wymagane: serwer z Docker (~$10/mc na DigitalOcean lub własny home server) i dwie subdomeny.

# 1. Klonuj repo git clone https://github.com/KSEGIT/polodoo.git cd polodoo # 2. Konfiguracja cp .env.example .env nano .env # ustaw POSTGRES_PASSWORD, ODOO_MASTER_PASSWORD, domeny # 3. Wszystko za jednym razem make quickstart # 4. Po starcie — onboarding spółki (NIP, REGON, IBAN, KSeF mode) make onboard-mnl make onboard-bioleaf # 5. Instalacja modułów make init-mnl make init-bioleaf
